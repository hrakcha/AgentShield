How AgentShield Works

Layer 1

Deterministic inspection for suspicious patterns and obfuscation (overrides, role hijacks, zero-width Unicode, encoded blobs).

Layer 2

Optional Gemini semantic classification of adversarial intent. If no API key is configured or the model fails, AgentShield uses a local deterministic fallback. The app does not require Gemini to run.

Decision

Allow / Review / Block from a transparent 0–100 risk score. Indicators describe a potential threat, not a proven attack.

Informational reference: OWASP Top 10 for LLM Applications (including LLM01: Prompt Injection). AgentShield is not OWASP-certified and does not claim compliance.
